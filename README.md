# Nebula · 大数据处理工具箱 v9.1

本地优先的桌面 / 手机网页工具箱：球球查询、赛季推算、文本清洗与排序、文档分类打包、批量改密，以及 6 个离线效率插件。

- **无框架、无 CDN、无构建**：双击 `index.html` 或用任意静态服务器打开即可。
- **数据不出本机**：除「球球查询器」会把输入词发给官方公开接口外，其余全部在浏览器内完成。
- **统一导出**：所有文本区 / 文件区都能改文件名；支持系统保存面板、同名覆盖、记住导入位置并直接写回原文件。
- **统一 5 万字上限**、统一主题（明亮 / 暗黑 / 跟随）、统一模块 UI 框。

## 这次改了什么（v9.1）

1. **插件区推翻重做**：移除便签、抽签等“小游戏”型入口，改成真正处理数据的 6 个插件：
   - 文本清洗（空行 / 去重 / 全半角 / 大小写 / 前后缀 / 行号）
   - 格式转换（CSV / TSV ↔ JSON / Markdown / SQL IN / 引号列表 / HTML 表格）
   - 数据脱敏（手机号 / 邮箱 / 身份证 / QQ / 球球号 / 自定义正则）
   - 批量替换（普通或正则替换、提取匹配）
   - 插件箱（JSON、时间戳、文本统计、正则、SHA 哈希、编码）
   - 编码实验室（原有）
2. **导出文件名修复**：不再默认走系统分享（分享会改写文件名）；下载严格使用你设置的名字，`a.txt.txt` 这类重复后缀会自动去掉。
3. **覆盖原文件**：用 Chrome / Edge 的“打开文件”面板导入后会保存文件句柄，导出弹窗会自动找到原文件，勾选「覆盖原文件」即可写回原位置，不再另存一份。
4. **文档分类**：修正 `打包.zip.zip`、基础名带扩展名、分件重名等 bug；新增“导出到文件夹”，可以直接写进你选择的目录（支持记住上次位置）。
5. **UI 框重做**：首页工具卡、插件台、模块面板、旧版工具页统一新边框 / 间距 / 玻璃层；卡片不再把标题截成“文档分类…”。
6. **动态升级**：首页数字滚动、最近使用、底部导航滚动自动收起、模块面板入场、插件台数据网格背景、粘性工具条。

## 使用

静态托管：

```bash
cd 大数据处理6
python3 -m http.server 8080
# 打开 http://127.0.0.1:8080/
```

> 用 `file://` 直接打开也能看，但 `localStorage`、iframe、剪贴板、文件句柄在部分浏览器会被限制，建议用静态服务器。

### 赞助后端（可选）

```bash
cd server
ADMIN_TOKEN=你的口令 ./start.sh
# 工具箱: http://127.0.0.1:8787/
# 管理页: http://127.0.0.1:8787/admin
```

赞助者提交后进入待审，作者在 `/admin` 点「通过」才会出现在感谢墙并计入总额。详见 `server/README.md`。

## 导出与覆盖规则

| 环境 | 行为 |
|---|---|
| Chrome / Edge（支持 File System Access API） | 导入时用系统面板打开文件，记住句柄；导出时可勾选「覆盖原文件」，直接写回原位置。也可用系统保存面板另选位置。 |
| 其他浏览器 / 手机 WebView | 弹出统一导出弹窗，文件名严格按输入保存；同名文件由浏览器生成 `(1)` 副本。系统分享只在你主动点「分享…」时使用。 |
| 无句柄但有同名导出记录 | 弹窗会提示同名文件，允许继续；不会假装能静默覆盖磁盘。 |
| 文档分类 | 可打包 ZIP，也可“导出到文件夹”；文件夹写入支持记住上次位置，分件直接写入所选目录。 |

浏览器不允许脚本静默改磁盘文件；本项目的“覆盖”是借助 File System Access API 的文件句柄实现的，没有句柄时会如实退回下载。

## 上限

- 文本 / 行数统一 50,000；超出会截断并提示。
- 文件导入上限 30MB（文件哈希也限制在 30MB 内）。

## 本地存储键

| 键 | 内容 |
|---|---|
| `ui_theme` / `ui_accent` / `ui_motion` / `ui_fx` / `ui_haptic` | 外观 |
| `nebula_profile` | 作者资料、赞助标记、后端地址 |
| `nb_files` | 导出文件库（判重 / 覆盖提示） |
| `nb_last_import` | 最近导入文件名（用于导出默认名） |
| `nb_draft_<page>` | 页面草稿（≤200KB，7 天） |
| `nb_season_table` | 自定义赛季表 |
| `nb_sponsors` | 离线模式下的本地赞助记录 |
| `bob_proxy` | 球球查询中转地址（原有） |

文件句柄存在 IndexedDB `nebula_fs_v2` 中，不会上传。「我的 → 清空所有数据」会清掉 localStorage 内容（不含已导出文件与 IndexedDB 句柄）。
